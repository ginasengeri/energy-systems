Alberta Market Data Pipeline

Technical appendix documenting how the January 2026 hourly dataset was collected from AESO public APIs, merged across sources, and validated for time coverage.

1) Goal

Build a single analysis table with one row per hour for 2026-01-01 00:00 → 2026-01-31 23:00 (MPT).

Date: Date (MPT)
Price: pool_price
Generation: GAS / WIND / HYDRO / SOLAR_daytime
Capability: ac
Interchange proxy: IMPORTER / EXPORTER

Metered volume = actual generation in the settlement hour (MW).
AC = available capability (MW): MC − (MBO OUT + OP OUT).

2) Data sources

  • Pool Price (hourly).
  • Metered Volume (hourly), aggregated by fuel type.
  • AIES Generation Capacity (hourly): MC, MBO OUT, OP OUT, AC.

3) Core merge

Datasets are aligned on Date (MPT) and merged into a single analysis table. 


price_vol = pd.merge(
pool_price,
wide_vol[['GAS','WIND','HYDRO','SOLAR_daytime']].reset_index(),
on='Date (MPT)'
)

price_vol_ac = pd.merge(
price_vol,
aies[['ac']].reset_index(),
on='Date (MPT)'
)

final = pd.merge(
price_vol_ac,
wide_asset_vol[['IMPORTER','EXPORTER']].reset_index(),
on='Date (MPT)'
)

final['total_generation'] =
final[['GAS','WIND','HYDRO','SOLAR_daytime']].sum(axis=1)

final['net_interchange'] =
final['EXPORTER'] - final['IMPORTER']

4) Data validation

January should contain 744 hourly observations (31 × 24). The pipeline verifies completeness by comparing expected timestamps to the merged dataset. 


expected = pd.date_range(
"2026-01-01 00:00",
"2026-01-31 23:00",
freq="H"
)

actual = pd.to_datetime(final["Date (MPT)"]).drop_duplicates()

missing = expected.difference(actual)

print("Expected:", len(expected))
print("Actual:", len(actual))
print("Missing:", len(missing))

Missing hours can occur when API calls are split across date ranges. Overlapping boundary days and removing duplicate timestamps prevents accidental gaps in the time series.

5) Output


final.to_csv("alberta_market_data.csv", index=False)

This CSV contains the final hourly dataset produced by the pipeline.
