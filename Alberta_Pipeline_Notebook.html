Alberta Market Data Pipeline

Technical appendix describing the data collection, processing, and validation steps used to construct the January 2026 hourly dataset.

Data were collected from publicly available AESO API endpoints and transformed into a single hourly table containing system price, generation by fuel type, system capability, and interchange. The pipeline begins with API retrieval followed by data flattening, aggregation, merging, validation, and final export.

Data sources

The dataset combines several hourly reports from the AESO public API.

  • Pool Price – hourly Alberta pool price
  • Metered Volume – hourly generation reported at the asset level
  • AIES Generation Capability – system capability and outage values

These reports are retrieved as JSON responses and converted into table format. 

import requests
import pandas as pd

headers = {"API-KEY": "YOUR_KEY"}

url = "AESO_API_ENDPOINT"

response = requests.get(url, headers=headers)
data = response.json()

Flattening nested JSON structures

Metered volume responses contain nested structures where each participant includes multiple assets and each asset includes a list of hourly volumes. These nested records are flattened into a row-level table. 

volume_rows = []

for participant_block in combined_ret:
    participant = participant_block["pool_participant_ID"]

    for asset in participant_block["asset_list"]:
        asset_id = asset["asset_ID"]

        for v in asset["metered_volume_list"]:
            v["pool_participant_ID"] = participant
            v["asset_ID"] = asset_id
            volume_rows.append(v)

metered_vol = pd.DataFrame(volume_rows)

Aggregation and reshaping

Asset-level metered volume data is aggregated by fuel type and timestamp. The resulting table is reshaped into wide format so each fuel type appears as a column. 

fuel_hourly = (
metered_vol
.groupby(["Date (MPT)", "fuel_type"])["metered_volume"]
.sum()
.reset_index()
)

wide_vol = fuel_hourly.pivot(
index="Date (MPT)",
columns="fuel_type",
values="metered_volume"
).reset_index()

Merging datasets

After aggregation, the generation data is merged with pool price and system capability datasets using the hourly timestamp as the common key. 

price_vol = pd.merge(
pool_price,
wide_vol[['GAS','WIND','HYDRO','SOLAR_daytime']].reset_index(),
on='Date (MPT)'
)

price_vol_ac = pd.merge(
price_vol,
aies[['ac']].reset_index(),
on='Date (MPT)'
)

Data validation

A validation step checks whether the expected number of hourly observations is present. January contains 744 hours (31 × 24). Missing timestamps are identified by comparing the dataset against a complete hourly index. 

expected = pd.date_range(
"2026-01-01 00:00",
"2026-01-31 23:00",
freq="H"
)

actual = pd.to_datetime(price_vol_ac["Date (MPT)"]).drop_duplicates()

missing = expected.difference(actual)

print(len(expected))
print(len(actual))
print(missing)

This check makes it possible to identify missing hours that can occur when API queries are split across multiple date ranges.

Final dataset

The final dataset contains one row per hour and combines price, generation, system capability, and interchange indicators. The table is exported as a CSV file for analysis and visualization. 

price_vol_ac_interchange.to_csv(
"alberta_market_data.csv",
index=False
)
