Alberta Market Data Pipeline

Technical appendix for the Alberta case study. This page documents how the January 2026 hourly dataset was collected from AESO public APIs, merged across sources, and validated (time coverage + missing hours).

1) Goal

Build a single table with one row per hour for: 2026-01-01 00:00 → 2026-01-31 23:00 (MPT).

Output Date (MPT) pool_price GAS / WIND / HYDRO / SOLAR_daytime ac IMPORTER / EXPORTER

Metered volume = actual generation in the settlement hour (MW).
AC = available capability (MW): MC - (MBO OUT + OP OUT).

2) Data sources

  • Pool Price (hourly).
  • Metered Volume (hourly) aggregated by fuel type; asset classes used for importer/exporter.
  • AIES Generation Capacity (hourly): MC, MBO OUT, OP OUT, AC.

All datasets are aligned on Date (MPT) and merged into a single “analysis table”.

3) Pipeline summary

Steps

  1. Pull each dataset for January 2026 (split calls where required).
  2. Aggregate to hourly totals and pivot to wide format.
  3. Merge: price + fuel generation + AC + importer/exporter.
  4. Validate expected hourly coverage and identify missing timestamps.
  5. Export final CSV.

Core merge (reference)

price_vol = pd.merge(
    pool_price,
    wide_vol[['GAS','WIND','HYDRO','SOLAR_daytime']].reset_index(),
    on='Date (MPT)'
)

price_vol_ac = pd.merge(
    price_vol,
    aies[['ac']].reset_index(),
    on='Date (MPT)'
)

final = pd.merge(
    price_vol_ac,
    wide_asset_vol[['IMPORTER','EXPORTER']].reset_index(),
    on='Date (MPT)'
)

4) Data validation

expected = pd.date_range("2026-01-01 00:00", "2026-01-31 23:00", freq="H")
actual = pd.to_datetime(final["Date (MPT)"]).drop_duplicates()
missing = expected.difference(actual)

5) Output

final.to_csv("alberta_market_data.csv", index=False)
