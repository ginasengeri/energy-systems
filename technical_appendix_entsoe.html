Work in Progress: ENTSO-E Data Pipeline

Technical appendix describing the retrieval and processing of hourly price and cross-border flow data for February 2026.

Transmission and market data were collected from the ENTSO-E Transparency Platform API and transformed into time-series datasets containing cross-border physical flows and zonal day-ahead electricity prices. The pipeline retrieves XML responses from the API, parses the structure, reconstructs timestamps, and converts the data into tabular format for analysis.

Data sources

Two datasets are retrieved from the ENTSO-E API:

  • Cross-border physical electricity flows between bidding zones
  • Day-ahead electricity prices for each zone

The following bidding zones are included in the dataset:

  • France (FR)
  • Germany–Luxembourg (DE-LU)
  • Netherlands (NL)
  • Norway Zone 2 (NO2)

All data are retrieved using authenticated requests to the ENTSO-E Transparency Platform API. 

import requests
import pandas as pd

url = "https://web-api.tp.entsoe.eu/api"

params = {
    "securityToken": API_KEY,
    "documentType": "A11"
}

response = requests.get(url, params=params)

Parsing XML responses

Each response contains one or more Period blocks describing a time interval, its temporal resolution, and a list of 15 minute observations. These nested structures are parsed using the Python XML ElementTree library. 

import xml.etree.ElementTree as ET

root = ET.fromstring(response.content)

for period in root.findall(".//{*}Period"):
    start = period.find("{*}timeInterval/{*}start").text
    resolution = period.find("{*}resolution").text

Each period contains a sequence of Point elements where the position indicates the minute within the interval and the value represents either the electricity flow or price for that interval.

Reconstructing timestamps

Timestamps are reconstructed from the period start time, the position of each observation, and the 15 minute resolution. This approach converts the period-based XML structure into explicit time records. 

for point in period.findall("{*}Point"):
    position = int(point.find("{*}position").text)
    value = float(point.find("{*}quantity").text)

    timestamp = start + (position - 1) * resolution

Each observation is stored as a row in a list which is later converted into a pandas DataFrame.

Constructing the flow dataset

Cross-border physical flows are retrieved for multiple directional pairs between bidding zones. For each pair, the API query specifies the exporting and importing domains. 

flows = {
"FR->DE-LU": ("10YFR-RTE------C","10Y1001A1001A82H"),
"DE-LU->FR": ("10Y1001A1001A82H","10YFR-RTE------C"),
"DE-LU->NL": ("10Y1001A1001A82H","10YNL----------L"),
"NL->DE-LU": ("10YNL----------L","10Y1001A1001A82H"),
}

Each observation records the flow direction, timestamp, and physical electricity flow value.

Constructing the price dataset

Day-ahead prices are retrieved for each bidding zone using a separate API query. Price observations are stored with the associated zone and timestamp. 

zones = {
"FR": "10YFR-RTE------C",
"DE-LU": "10Y1001A1001A82H",
"NL": "10YNL----------L",
"NO2": "10YNO-2--------T"
}

The resulting dataset contains hourly zonal prices aligned with the same timestamp structure used for the flow data.

Timezone conversion

ENTSO-E timestamps are returned in Coordinated Universal Time (UTC). For consistency with European market conventions, timestamps are converted to Central European Time (CET/CEST) using the Brussels timezone and stored as naive local datetimes. 

df["time"] = (
pd.to_datetime(df["time"], utc=True)
  .dt.tz_convert("Europe/Brussels")
  .dt.tz_localize(None)
)

Two structured tables are produced:

  • flows_df – cross-border electricity flows by direction
  • prices_df – day-ahead electricity prices by bidding zone
