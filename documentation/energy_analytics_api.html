Energy Analytics API

Documentation for accessing data quality information for datasets used in modelling.

The Energy Analytics API provides access to data quality information to support transparency and reproducibility of each model by identifying missing or incomplete observations in the input data.

Data quality endpoint

The API endpoint returns a JSON data quality report for a specified energy market dataset.

GET/{grid}/{dataset}/{quarter}/{year}/

Example request:

http://127.0.0.1:8000/pjm/ess-model/Q3/2025/

In Python:

grid = "pjm"
dataset = "ess-model"
quarter = "Q3"
year = "2025"

url = f"http://127.0.0.1:8000/{grid}/{dataset}/{quarter}/{year}/"

response = requests.get(url)
data = response.json()

df = pd.DataFrame(data)

df

Parameters

ParameterDescriptionCurrently supported
gridThe grid operator or ISO the dataset belongs to.pjm
datasetThe specific dataset or model input being queried.ess-model
quarterThe calendar quarter covered by the report.Q3
yearThe calendar year covered by the report.2025

The relevant parameters for each model can be found under its respective Data Quality & Validation section.

Response format

Each report summarizes gaps or irregularities found in the requested dataset, including missing observations, any interpolation or exclusions, and relevant notes on how those gaps were handled.
