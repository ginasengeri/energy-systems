PJM Energy Storage System Model

Data quality & validation for the energy storage system (ESS) optimization model

This page documents data quality details for the PJM ESS optimization model, queried via the Energy Analytics API (grid=pjm, dataset=ess-model). The model optimizes revenue for a 100 MW / 400 MWh battery from July 1st to October 1st, prior to the unifying of the RegA and RegD in PJM's market.

Key Notes

  1. The performance, perf, dataset is missing an observation at 2025-08-22 03:00 UTC (2025-08-21 23:00 local time). This row was excluded to ensure the model receives complete data for every hour.

  2. The regulation signal uses normalized sample data from October 3, 2025. This is repeated across the Q3 2025 modeling period because the required AGC signal data was inaccessible.

  3. Regulation revenue is calculated using the RegA product only, due to data-permission limitations.

  4. RMCCP and RMPCP are used to determine regulation prices in accordance with PJM Manual 11/28.
