Energy Analytics API Documentation The Energy Analytics API provides access to metadata and data-quality information for datasets used in energy-system modelling. This documentation provides transparency and reproducibility of the model by identifying missing or incomplete observations in input data. ESS PJM: -------- A missing row in the regulation-details dataset resulted in NAN values in the final merged ess-model dataset, on 2025-08-22 at 03:00:00 UTC / 2025-08-21 at 23:00:00 local time. This data is missing from PJM's public database: https://dataminer2.pjm.com/feed/reg_market_results. The row was excluded from input data for the ESS optimization model. The model simulates a battery's operations from 1st July to 1st October, prior to the unifying of the RegA and RegD signals into one unified signal. This means mileage ratios represent the ratio between RegD and RegA, as per market rules prior to the change on October 1st. In addition, and RMCCPs and RMPCPs are used to determine prices for commited regulation. For regulation service revenues, only the RegA product is considered due to data accessibility limitations. 1.
