Ember Data Pipeline

Technical appendix describing the data collection, processing, and validation steps used to construct the annual electricity generation datasets.

Data were collected from publicly available Ember API endpoints and transformed into tabular datasets for analysis of annual electricity generation by country and source. The pipeline begins with API retrieval followed by table conversion, column standardisation, filtering, aggregation, validation, and final export.

Data sources

The dataset uses the Ember electricity generation API and retrieves yearly generation data for selected countries and fuel categories.

  • Yearly electricity generation by country
  • Generation by source or technology
  • Country-level values used directly or combined into regional aggregates

These reports are retrieved as JSON responses and converted into table format. 

import requests
import pandas as pd

my_api_key = "YOUR_KEY"
base_url = "https://api.ember-energy.org/v1/electricity-generation/yearly"

query_url = (
    f"{base_url}?entity_code=UGA,KEN,ETH,RWA,TZA&"
    "is_aggregate_series=false&"
    "start_date=2019&"
    "end_date=2024&"
    f"api_key={my_api_key}"
)

response = requests.get(query_url)
data = response.json()

Converting API responses to a table

The Ember API returns a JSON object containing a dataset of yearly records. These records are loaded directly into a pandas DataFrame. 

df = pd.DataFrame(data["data"])
print(data.keys())
print(df.head())

Cleaning and standardising fields

Non-essential metadata fields are removed and net imports are excluded where the analysis is intended to focus on domestic generation only. 

df.drop(columns=["is_aggregate_entity", "is_aggregate_series"], inplace=True)

df = df.rename(columns={
    "series": "source",
    "entity": "country",
    "entity_code": "country_code"
})

df = df[df["source"] != "Net imports"]

Aggregation and regional construction

Generation is reported for individual countries in the East African generation analysis. The ENTSO-E system combines Germany and Luxembourg into a single DE-LU series. In this case, records for DEU and LUX are grouped by source and summed to create a regional total. The regional share of generation is then calculated from the summed total to approximate the mix in this zone. 

delu = (
    df[df["country_code"].isin(["DEU", "LUX"])]
    .groupby("source", as_index=False)["generation_twh"]
    .sum()
)

delu["country"] = "Germany–Luxembourg"
delu["country_code"] = "DE-LU"
delu["date"] = 2025

total = delu["generation_twh"].sum()
delu["share_of_generation_pct"] = (
    delu["generation_twh"] / total * 100
).round(1)

Netherlands, Norway, and France are then appended to the DE-LU aggregate to produce a combined table. 

others = df[df["country_code"].isin(["NLD", "NOR", "FRA"])].copy()
final = pd.concat([delu, others], ignore_index=True)

Validation

A validation step checks that the API response contains the expected date range and no duplicate source-country-year combinations before and after aggregation. 

print("Date range:", df['date'].unique())

print("Duplicates before aggregation:", df.duplicated(subset=['source', 'country_code', 'date']).sum())
print("Duplicates after aggregation:", final.duplicated(subset=['source', 'country_code', 'date']).sum())

Final dataset

The final datasets contain annual generation values by source for the selected countries and regions. 

final.to_csv("ember_generation_output.csv", index=False)
